# Progress – 2026-01-20

## Summary
- Implemented a non-blocking, poll-driven write path with per-client output buffering to comply with the “single poll for I/O” requirement.
- Routed all IRC responses and channel broadcasts through the queued send path.
- Fixed cleanup to prevent leaks by deleting clients/channels on shutdown.
- Ensured the server socket is non-blocking and handled `POLLOUT` events.

## Details
- Added `outBuffer` to `Client` with helper methods.
- Added `QueueMessage`, `HandleWrite`, `UpdatePollOut`, and `GetClientByFd` in `Server`.
- Updated `Channel::Broadcast` to use server queue instead of direct `send()`.
- Replaced all direct `send()` calls in commands with `QueueMessage()`.
- Added `SIGPIPE` ignore to avoid crashes on broken pipes.
- Added `<cerrno>` for non-blocking send error handling.
